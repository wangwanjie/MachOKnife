MachOKnife

原生 macOS Mach-O 查看与编辑工具。MachOView 风格的结构浏览器，加上重写平台标记、打包 XCFramework、合并 / 拆分 / 移除架构、污染检查等常用二进制工具，同样的能力也可以通过命令行 machoe-cli 使用。 A native macOS app for inspecting and editing Mach-O binaries. A MachOView-style structure browser plus everyday binary tools — retag, XCFramework packaging, merge / split / remove architectures, contamination checks — with the same tooling in the machoe-cli command-line utility.

命令行工具Command-line tool

在「偏好设置 › CLI」中安装随 App 提供的 machoe-cli，运行 machoe-cli help <command> 查看全部选项。Install the bundled machoe-cli from Preferences › CLI, then run machoe-cli help <command> for every option.

machoe-cli info /path/to/binary # per-slice overview, add --json
machoe-cli check-contamination libSDK.a --mode architecture --target arm64
machoe-cli merge arm64/libSDK.a x86_64/libSDK.a --output /tmp/libSDK.a
machoe-cli remove-arch MyLib.framework/MyLib --arch x86_64 --in-place
machoe-cli retag-platform libExample.dylib --platform macos --min 13.0 --sdk 14.0 --output /tmp/out.dylib
machoe-cli build-xcframework --source-library libSDK.a --ios-simulator-source-library libSDK-sim.a \
  --headers-dir Headers --output /tmp/SDK.xcframework
machoe-cli validate /path/to/binary

安装Install

不确定芯片类型？打开「苹果菜单 › 关于本机」，看“芯片”或“处理器”一栏。Not sure which chip you have? Open › About This Mac and check “Chip” or “Processor”.

  1. 下载与本机芯片匹配的 DMG，打开后把 MachOKnife 拖进「应用程序」文件夹。Download the DMG for your chip, open it and drag MachOKnife into Applications.
  2. 从「应用程序」中打开 MachOKnife，把 Mach-O 文件拖进窗口，或用「文件 › 打开」、访达「打开方式」打开。Launch MachOKnife and drop a Mach-O file onto the window, or use File › Open… or Finder’s “Open With”.
  3. 需要命令行时，在「偏好设置 › CLI」中把 machoe-cli 安装到 PATH 中的目录。For the CLI, install machoe-cli into a directory on your PATH from Preferences › CLI.
  4. App 通过 Sparkle 自动更新，只会下载与本机芯片匹配的版本；也可以在「偏好设置 › 更新」中调整检查频率。Updates arrive through Sparkle and always match your chip; adjust the check schedule in Preferences › Updates.
