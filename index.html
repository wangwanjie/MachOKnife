02
结构浏览器

每个字段都标出偏移与原始字节

左侧结构树，右侧字段级 Detail 表与十六进制 Data 视图，排布方式与 MachOView 一致。

DETAIL A · 1 : 1
A1

完整结构

Mach 头、加载命令、段与节、dyld info / chained fixups、导出 trie、符号表 / 间接符号表 / 字符串表、代码签名、Objective-C 元数据与重定位。

A2

各种容器

单架构与通用（fat）二进制、静态库 .a，以及 dyld shared cache。

A3

RAW / RVA 双地址

两种地址模式随时切换，字段级 Detail 表与十六进制 Data 视图并列。

A4

大文件不卡

符号、字符串等重型分组按需解码，打开大型二进制依然流畅。

A5

搜索与复制

结构搜索，⌘C 复制选中行，右键菜单复制或导出。

A6

顺手的打开方式

拖放、「文件 › 打开」、访达「打开方式」与「打开最近使用」，最近文件在重启后保留。

03
Tools 菜单

改写、打包、拆合与排查

每个工具打开时都会自动带入工作区中当前打开的文件。

DETAIL Bretag-platform

Retag

改写平台、最低系统版本与 SDK 元数据，例如把 iOS 切片转成 Mac Catalyst 切片。

DETAIL Cbuild-xcframework

构建 XCFramework

把 iOS 真机 / 模拟器静态库与头文件打包成 XCFramework，可选自动生成 Mac Catalyst 切片。

DETAIL Dcheck-contamination

二进制污染检查

找出平台或架构与预期不符的切片，比如上架前混进去的模拟器切片。

DETAIL Emerge · split · remove-arch

合并 / 拆分 Mach-O

把多个切片合并为通用文件，按架构拆分 fat 文件，或直接剔除不需要的架构。

04
machoe-cli

同样的能力，写进脚本和 CI

下面的终端回放是 machoe-cli v1.7.0 对 /bin/ls 副本的真实输出：先查出多余架构，剔除后再复查。

zsh — /tmp/demo

点击上方标签切换场景；终端离开视口时回放自动暂停。

命令作用
info按切片查看 Mach-O 或静态库元数据，支持 --json
summary输出简明概览，支持 --json
list-dylibs列出依赖的 dylib 与 LC_RPATH，支持 --json
check-contamination检测与目标不符的平台或架构切片，不符时退出码为 1
validate校验结构与签名元数据，有问题时退出码为 1
merge · split合并多个切片，或按架构拆分
remove-arch从通用二进制或 fat 静态库中移除架构
retag-platform改写平台、最低系统与 SDK 版本
build-xcframework把静态库与头文件打包成 XCFramework
set-id · rewrite-rpath修改 dylib 的 install name，改写匹配的 LC_RPATH
strip-signature移除代码签名加载命令
fix-dyld-cache-dylib把 dyld cache 风格的 dylib 修正为可正常加载
  • 报告写到 stdout，错误写到 stderr；用法错误退出码 64，检查未通过退出码 1。
  • 编辑类命令不会悄悄覆盖输入：--output 必须与输入不同，remove-arch 需显式加 --in-place 才会原地改写。
  • 单值选项重复给出会直接报错，不会随便选一个。
在 App 的「偏好设置 › CLI」中选择一个位于 PATH 上的目录（如 /usr/local/bin）安装，之后运行 machoe-cli help <command> 查看每条命令的全部选项。

下载

按芯片选择安装包

每个版本按架构分别提供 DMG，体积更小；应用内更新会自动推送与本机匹配的版本。

推荐
arm64

Apple 芯片

M1 及之后的 Mac。

MachOKnife_V_<version>_arm64.dmg
下载 DMG
推荐
x86_64

Intel

使用 Intel 处理器的 Mac。

MachOKnife_V_<version>_x86_64.dmg
下载 DMG

系统要求与安装

  • macOS 13.0 或更高版本
  • Apple 芯片或 Intel Mac（选对应的 DMG）

不确定是哪种？打开左上角苹果菜单 › 「关于本机」：显示「芯片 Apple M…」是 Apple 芯片，显示「处理器 Intel…」是 Intel。

打开 DMG，把 MachOKnife 拖进「应用程序」后启动。安装包经 Developer ID 签名并由 Apple 公证，之后通过 Sparkle 自动更新。
