## Highlights

- 重写 Mach-O 浏览解析引擎，字段、偏移与原始数据对齐 MachOView：覆盖 Mach 头、Load Commands、Section、Dyld Info、Chained Fixups、导出表、符号表/间接符号表/字符串表、代码签名、ObjC 元数据与重定位，并统一支持 Universal 二进制与静态库
- 大文件的符号、字符串等重型分组改为按需解析，打开大型二进制依然流畅；无法识别的文件给出明确提示
- 修复 64 位地址被截断为 32 位显示的问题，地址列标题随 Raw / RVA 模式切换，Hex 视图列标题补齐本地化
- XCFramework 构建：修复单输入时真机 arm64 被误判为模拟器切片导致构建失败，保留静态库中的同名目标文件，产物先在临时目录生成后再替换输出，并校验产物名称
- CLI 参数解析与退出码更严格；重标记、合并/拆分等耗时操作移出主线程，避免界面卡顿
- 修复最近文件书签刷新、菜单状态、污染检测重复触发等问题，并补充回归测试
