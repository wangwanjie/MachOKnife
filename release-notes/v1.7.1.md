## Highlights

- 修复 Retag、编辑或剥离签名后的通用（fat）二进制无法再用 `codesign` 签名的问题：裁掉签名后会像 `lipo` 一样按对齐要求重新排布各切片
- 正确识别 `arm64e.x1` / `arm64.x1` 等新架构子类型（如 macOS 自带的 `/bin/ls`），结构树、摘要、合并 / 拆分、移除架构与 CLI 不再把它误认成 `arm64` 或 `armv7k`；拆分这类文件不再因重名失败
- 大文件打开时完整解析也移到后台，32–64 MB 的二进制不再卡住界面；连续打开多个文件时始终显示最后打开的那个
- 界面优化：结构树侧栏默认更宽并记住拖动后的宽度；RVA 模式下 64 位地址与 16 字节数据不再被截断；Retag、合并 / 拆分工具的状态提示会根据当前缺少的步骤给出下一步；工具窗口布局与对齐调整；移除没有实际内容的「高级」设置页

## 稳定性与修复

- 修复打开内核、kext 等超大虚拟地址的文件、畸形 fat 文件、超大段偏移、异常 chained fixups / 导出 trie / 代码签名时可能崩溃、卡死或占满内存的问题
- 修复 chained fixups（arm64e、firmware 等格式）指针目标、Entitlements 偏移、对齐显示等解析值错误；chained fixups 改为按需解析
- Retag zippered（macOS + Mac Catalyst）目标文件时不再残留旧平台；改写到 macOS 等平台时不再留下重复的版本命令
- 老式 Intel 模拟器库（`LC_VERSION_MIN_IPHONEOS` 等）的污染检查结论不再相反
- 合并 / 移除架构时输出路径是已有目录不会再把目录删掉；总大小接近 4 GiB 时自动使用 fat64
- 通过符号链接原地编辑 framework 二进制时改写真实文件，不再破坏 framework 结构
- XCFramework 构建：保留 arm64e 真机切片、头文件自带的 modulemap 正确随头文件移动、umbrella header 包含子目录头文件、复制 C++ 头文件、失败时给出简洁的错误信息；构建日志不再出现中文乱码
- 静态库写入失败时不再丢失原文件；超长成员名不再卡死
- 拖放只接受本地文件，结构树区域也支持拖入打开；Retag 运行中拖入新文件不再导致无法取消；污染检查进行中不再显示上一次的报告
- CLI：选项漏写取值时不再把下一个选项当成值、空路径与开关带值给出明确错误；`validate` 检查 fat 文件时按切片边界校验；错误信息附带完整路径；替换已有 xcframework 失败时保留旧产物
- 菜单文案统一使用省略号「…」，中文菜单中应用名前补齐空格
- 补充大量回归测试，覆盖解析加固、写回、Retag、工具服务、CLI 与界面逻辑
